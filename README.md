
# Automated Segmentation of SEM Fractographs Using Python

## Project Objective
Develop a Python-based application to segment Scanning Electron
Microscope (SEM) fractographs into void, surface, and mixed regions.

The implementation will follow the conventional image-processing
methodology described in the reference research paper.

## Technologies
- Python
- NumPy
- OpenCV
- scikit-image
- SciPy
- Matplotlib
- pandas
- pytest
- Visual Studio Code
- Git

## Windows Setup
1. Create a virtual environment using `py -m venv .venv`.
2. Activate it using `.\.venv\Scripts\Activate.ps1`.
3. Install dependencies using `python -m pip install -r requirements.txt`.
4. In VS Code, open this project folder and select `.venv\Scripts\python.exe` with **Python: Select Interpreter**.
5. Verify packages using `python environment.py`.
