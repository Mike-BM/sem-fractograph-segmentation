# Task 6: Void Detection and Extension

## 1. Objective

The objective of this task was to implement a two-stage void-detection method for Scanning Electron Microscope (SEM) fractograph images using Python and OpenCV. The method identifies candidate void-tip pixels from grayscale intensity values and attempts to extend the detected regions using local intensity statistics.

## 2. Input Image and Environment

- **Input image:** `100Cr6_AR_05_11.png`
- **Dataset category:** Brittle
- **Image dimensions:** 500 × 500 pixels
- **Image format:** Grayscale
- **Programming language:** Python
- **Libraries:** OpenCV, NumPy, Matplotlib
- **Input path:** `data/raw/Brittle/100Cr6_AR_05_11.png`

## 3. Stage A: Void-Tip Detection

The grayscale intensity histogram was calculated using OpenCV. The histogram was smoothed to reduce small intensity fluctuations, and the first detected local maximum in the selected low-intensity range was used as the void-tip threshold.

Pixels with grayscale intensities less than or equal to the selected threshold were classified as candidate void-tip pixels.

The selected threshold was **4**, producing 4,173 initial candidate pixels. The resulting binary mask was saved as `void_tip_mask.png`.

## 4. Stage B: Void-Tip Extension

The implementation identified connected components in the candidate tip mask and examined local neighborhoods around the components.

For each processed neighborhood, the local mean intensity and standard deviation were calculated. A paper-inspired extension threshold was applied:

\[
I_v = \max(\mu_l - 0.5\sigma_l,\ I_t)
\]

where:

- \(I_v\) represents the extension threshold.
- \(I_t\) represents the void-tip intensity threshold.
- \(\mu_l\) represents the local mean grayscale intensity.
- \(\sigma_l\) represents the local grayscale intensity standard deviation.

Pixels satisfying the extension threshold within the selected local neighborhoods were considered candidate void pixels. A minimum connected-component area filter was applied to reduce small isolated regions.

This stage expanded the initial candidate mask. However, expansion alone does not confirm that all additional pixels represent genuine physical voids.

## 5. Results

The corrected implementation executed successfully on the selected 500 × 500 grayscale SEM image.

| Measurement | Result |
|---|---:|
| Image dimensions | 500 × 500 pixels |
| Void-tip intensity threshold | 4 |
| Initial void-tip candidate pixels | 4,173 |
| Final void-candidate pixels | 59,367 |
| Pixels added outside the initial tip mask | 55,331 |
| Initial tip pixels absent from the final mask | 137 |
| Final candidate coverage | 23.75% |

The initial tip-detection stage identified 4,173 candidate pixels using a grayscale intensity threshold of 4. After local-threshold processing and filtering, the final candidate mask contained 59,367 pixels, corresponding to 23.75% of the image.

The final mask contained substantially more pixels than the initial tip mask, indicating that the extension stage expanded the candidate regions. A total of 55,331 pixels were added outside the initial tip mask, while 137 initial tip pixels were absent from the final mask.

These measurements describe the algorithm's output rather than validated physical void coverage. Visual inspection and comparison against manually annotated reference masks are required to evaluate segmentation quality.

## 7. Limitations and Validation

The implementation demonstrates a preliminary histogram-based void-tip detection and local-threshold processing workflow. However, the first detected low-intensity histogram peak may not always correspond to a genuine void-tip intensity.

The extension stage expanded the candidate mask substantially. Nevertheless, this does not establish that the added pixels correspond to actual void regions. Some surface pixels may have been included, and some genuine void pixels may have been omitted.

The results have not been validated against manually annotated pixel-level ground-truth masks. Consequently, segmentation metrics such as precision, recall, and intersection over union (IoU) have not been established.

The current implementation also does not provide a verified distinction between deep and shallow voids using all the relevant criteria from the reference paper. The local-threshold formula is paper-inspired, but the implementation has not been demonstrated to reproduce the paper's complete methodology.

The results should therefore be described as an experimental implementation rather than a validated reproduction of the complete reference-paper algorithm.

## 8. Conclusion

Task 6 established an experimental Python workflow for grayscale histogram analysis, candidate void-tip detection, local intensity processing, binary-mask generation, and visual inspection of candidate void regions.

The corrected implementation expanded the initial candidate mask from 4,173 pixels to 59,367 pixels, corresponding to 23.75% of the image. These results demonstrate that the implemented extension stage modifies and expands the candidate regions, but they do not establish segmentation accuracy.

Further work is required to verify the threshold-selection method, assess the physical validity of the detected regions, implement and evaluate deep-versus-shallow void classification, and compare the segmentation results against annotated reference masks.
